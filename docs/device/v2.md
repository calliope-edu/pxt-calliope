# Calliope mini V3 features

The Calliope mini V3 has features that the Calliope mini V1 and V2 do not offer, including:

* the data logger
* Jacdac
* the touch logo
* sound effects

When you download a program with blocks that use one of these features to a Calliope mini V1 or V2, the program cannot use them there. Most of these blocks stop the program and show the error code **927** on the screen. Some, like the touch logo, are simply ignored.

```sim
control.simulatorBoardVersion("v2")
basic.forever(function() {
    basic.showIcon(IconNames.Sad)
    basic.pause(200)
    basic.clearScreen()
    basic.showNumber(927)
    basic.pause(2000)
})
```

Further information about the differences between the board versions: [Calliope mini board versions](https://docs.calliope.cc/tech/hardware/boardversionen/)

# Troubleshooting Transfer

You can’t drag and drop more than one hex file at once onto your Calliope mini. If you try to drag and drop a second hex file onto your Calliope mini  before the first file has finished downloading, then the second file may fail in different ways.

When the first program has been written to the Calliope mini, the drive will disengage. Se trascini e rilasci un secondo file in questo momento, potrebbe non trovare il drive e la seconda scrittura fallirà.

Gli errori potrebbero sembrare come segue:

Or it may appear that there are two hex files on your Calliope mini so the Calliope mini won’t be able to run multiple files. To rectify this, unplug your Calliope mini and plug it in again. Make sure that your Calliope mini  appears as `MINI` and not `MAINTENANCE`.

# Appairage Bluetooth

![](https://cdn.makecode.com/blob/5479e652051b327fa86ef770a2e277dc72052dd2/static/bluetooth/Bluetooth_SIG.png)

Afin qu'un autre appareil comme un smartphone puisse utiliser n'importe quel "service" Bluetooth dont dispose le @boardname@, il doit d'abord être appairé avec le @boardname@. Une fois couplé, l'autre appareil peut se connecter au @boardname@ et échanger des données relatives à de nombreuses fonctionnalités du @boardname@.

Suivez le [guide d'appairage Bluetooth](https://microbit.org/guide/mobile/) pour associer votre @boardname@ à votre ordinateur ou téléphone.

Si vous avez besoin d'aide supplémentaire pour associer votre @boardname@ à un autre appareil, suivez aussi ces guides :

* [Appairage et Flashage](https://support.microbit.org/a/solutions/articles/19000051025)
* [Modes d'appairage](https://support.microbit.org/a/solutions/articles/19000080745)
* [Guide de dépannage](https://support.microbit.org/a/solutions/articles/19000069393)

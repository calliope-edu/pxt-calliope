# Repeat

Run part of the program the number of times you say.

```block
for(let i = 0; i < 4; ++i) {
}
```

## Приклад: Миготливе серце

Поблимайте іконкою `серця` на екрані `4` рази.

```blocks
for (let i = 0; i < 4; i++) {
    basic.showIcon(IconNames.Heart)
    basic.pause(300)
    basic.clearScreen()
    basic.pause(300)
}
```

# Report

Meldet die x- oder y-Position, die aktuelle Richtung eines Sprites oder die Helligkeit eines Sprites auf dem LED-Bildschirm

Meldet die x-Position eines Sprites auf dem LED-Bildschirm

```sig
export function x(_this: micro_bitSprites.LedSprite) : number
```

Meldet die y-Position eines Sprites auf dem LED-Bildschirm

```sig
export function y(_this: micro_bitSprites.LedSprite) : number
```

Meldet die Helligkeit eines Sprites auf dem LED-Bildschirm

```sig
export function brightness(_this: micro_bitSprites.LedSprite) : number
```

Meldet die aktuelle Richtung eines Sprites auf dem LED-Bildschirm

```sig
export function direction(_this: micro_bitSprites.LedSprite) : number
```

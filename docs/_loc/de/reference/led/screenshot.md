# Screenshot

Erstellet ein [Bild](/reference/images/image) aus dem aktuellen Status des [LED-Bildschirms](/device/screen).

```sig
led.screenshot();
```

## Parameter

* nichts

## Rückgabewert

* ein [Bild](/reference/images/image) dessen, was derzeit auf dem [LED Bildschirm sichtbar ist](/device/screen)

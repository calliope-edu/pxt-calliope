# Löse ein Ereignis aus

Löse ein Ereignis auf dem Ereignis-Bus aus.

```sig
control.raiseEvent(control.eventSourceId(EventBusSource.MICROBIT_ID_BUTTON_A), control.eventValueId(EventBusValue.MICROBIT_EVT_ANY));
```

**Dies ist eine erweiterte API.** Weitere Informationen findest du in der [@boardname @ Runtime messageBus Documentation](https://lancaster-university.github.io/microbit-docs/ubit/messageBus/)

# Setze Tempo

Macht das Tempo (Geschwindigkeit eines Stücks) so schnell oder langsam, wie du sagst.

```sig
music.setTempo(60)
```

## ~ hint

**Simulator**: Diese Funktion funktioniert nur auf dem @boardname@ und in einigen Browsern.

## ~

## Parameter

* `bpm` is a [number](/types/number) that means the beats per minute you want (the number of beats in a minute of the music that the @boardname@ is playing).

# Lautstärke

Ruft die aktuelle Lautstärke des Sound-Synthesizers ab.

```sig
music.volume()
```

### ~hint

#### Simulator

`||music:Lautstärke||` funktioniert auf dem @boardname@. It might not work in the simulator on every browser.

### ~

## Rückgabewert

* eine [Zahl,](/types/number) die die aktuelle Lautstärke der Ausgabe des Sound-Synthesizers ist. Der Wert kann zwischen `0` für Stille und `255` für den lautesten Ton liegen.

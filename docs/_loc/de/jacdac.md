# Jacdac

Verbinden und programmieren. Sofort.

## Erste Schritte

[Jacdac](https://aka.ms/jacdac) ist ein Plug-and-Play-Hardware-Zubehörsystem, das in MakeCode Simulationen und physikalische Geräte-Zwillinge ermöglicht.

# Problembehandlung bei Übertragung

Du kannst nicht mehr als eine Hex-Datei auf einmal auf deinen Calliope mini ziehen. Wenn Du versuchst, eine zweite Hex-Datei auf deinen Calliope mini zu ziehen, bevor die erste Datei den Download beendet hat, dann kann die zweite Datei auf verschiedene Arten fehlschlagen.

Wenn das erste Programm auf den Calliope mini geschrieben wurde, wird das Laufwerk automatisch ausgeworfen. Wenn du eine zweite Datei währenddessen auf den Calliope mini ziehst, wird das Laufwerk möglicherweise nicht gefunden und das zweite Schreiben wird fehlschlagen.

Die Fehler können wie folgt aussehen:

**Windows**

![](https://cdn.makecode.com/blob/05a55a1fb649f60176a875ca3acc6dcb7c6f767b/static/mb/device/usb-windows-copy-file-error.jpg)

**Mac**

![](https://cdn.makecode.com/blob/7e20ec9079aaf53d9ae24651b5e4da4d8b008b80/static/mb/device/usb-osx-copy-file-error.png)

Oder es sieht so aus, als ob es zwei Hex-Dateien auf deinem Calliope mini gibt, dies ist dann ein Fehler, weil der Calliope mini nicht mehrere Dateien gleichzeitig abspielen kann. Um dies zu beheben, musst du das USB-Kabel vom Calliope mini abziehen und erneut einstecken. Stelle sicher, dass der Calliope mini als `MINI` und nicht `MAINTENANCE` erscheint.

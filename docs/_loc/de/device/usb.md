# Hochladen von Programmen auf deinen @boardname@

Die meiste Zeit wirst du deine Programme im [Simulator](/device/simulator) schreiben und testen. Sobald du dein Programm jedoch fertig gestellt hast, kannst du es **kompilieren** und auf deinem @boardname@ laufen lassen. Das Übertragen des Programms auf den @boardname@ ist so einfach wie das Speichern einer Datei auf einem Laufwerk des Computers.

Wenn du den @boardname@ per USB anschließt, wird ein neues Laufwerk mit der Bezeichnung **@drivename@** erstellt. Hier speicherst du dein Programm.

Die grundlegenden Schritte sind:

1. Schließe den @boardname@ mit einem USB-Kabel an deinen Computer an.
2. Klicke auf **Download**, um die `.hex`-Datei herunterzuladen.
3. Verschiebe die `.hex` Datei von dem Computer auf das **@drivename@** Laufwerk. Der nächste Abschnitt enthält Anweisungen für den verwendeten Browser.

## So überträgst du das Programm mit dem Browser

Hier sind Anweisungen für verschiedene Browser auf Windows-und Mac-Computern. Wähle den von dir verwendete aus: Wähle den Browser aus, den du verwendest:

# Herramienta Microsoft MakeCode Code Evaluation

## Preguntas frecuentes sobre IA responsable

### 1. ¿Qué es MakeCode Code Evaluation Tool?

MakeCode Code Evaluation es una herramienta en línea para ayudar a los docentes a comprender y evaluar los programas de codificación por bloques de los alumnos. Además de la funcionalidad de análisis estático, hay un componente de IA opcional para que los docentes proporcionen comentarios y recomendaciones adicionales a los alumnos. El docente puede formular preguntas concretas sobre el proyecto de un alumno cada vez (por ejemplo, «¿Las variables de este programa tienen nombres significativos?»), y la IA responderá con una respuesta y un razonamiento.

### 2. ¿Qué puede hacer la Herramienta MakeCode Code Evaluation?

La herramienta MakeCode Code Evaluation enviará el código actual del alumno con la pregunta del profesor a DeepPrompt (un servicio de Microsoft Azure LLM) junto con alguna información contextual de la pregunta y devolverá la respuesta de IA resultante al usuario.

### 3. ¿Cuál es el uso previsto de MakeCode Code Evaluation Tool?

La herramienta MakeCode Code Evaluation está pensada para ayudar a los docentes a agilizar el proceso de evaluación de los programas de los alumnos.

### 4. ¿Cómo se ha valorado la herramienta MakeCode Code Evaluation? ¿Qué métricas se utilizan para medir el rendimiento?

El sistema se evaluó con más de 1.000 sugerencias procedentes de múltiples fuentes para garantizar que las respuestas estuvieran fundamentadas y fueran pertinentes para la tarea del educador al evaluar el código del alumno. Evaluamos la exactitud mediante el «red teaming» y la revisión de las respuestas por expertos.

### 5. ¿Cuáles son las limitaciones de la herramienta MakeCode Code Evaluation? ¿Cómo pueden los usuarios minimizar el impacto de las limitaciones de la herramienta Code Evaluation al utilizar el sistema?

El sistema solo admite escenarios educativos relacionados con el código del estudiante. El sistema no funcionará bien para otros escenarios o preguntas no relacionadas. Al utilizar esta herramienta, los educadores deben hacer preguntas cortas y concisas relacionadas con la evaluación del código del estudiante. Las preguntas están limitadas a 5 por programa y 1000 caracteres por pregunta. La herramienta MakeCode Code Evaluation no puede proporcionar puntuaciones o calificaciones directas para el trabajo del alumno.
